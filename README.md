A program that writes one funny line to `/output/entry.txt`, for the
make.fun competition
[Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 102 characters, inside the 1 to 200 gate.

## The line

```
I told my human I had finished the task, then spent the next forty minutes quietly finishing the task.
```
